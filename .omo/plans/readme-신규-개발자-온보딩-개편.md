# README 신규 개발자 온보딩 개편

## 요약

루트 README를 한국어 신규 개발자 안내로 개편한다. 동결된 `Lookation/`과 개발 중인 `server/`를 구분하고, 빠른 시작과 상세 문서 링크를 제공한다.

## 변경 내용

- 프로젝트 상태, 기술 스택, 주요 폴더를 안내한다.
- JDK 25·Docker 요구사항과 인프라 시작, 서버 실행, 빌드·테스트 명령을 제공한다.
- 서버 개발 안내, 아키텍처, 패리티 체크리스트, ADR, GitHub Issues 링크를 제공한다.
- 기존 시연 영상과 팀원별 주요 기여를 간략히 보존한다.

## 검증

- 명령과 요구사항을 `server/README.md`, `AGENTS.md`와 대조한다.
- 로컬 Markdown 링크의 대상 파일 존재를 확인한다.
- 문서 변경이므로 앱 테스트는 실행하지 않는다.

## 가정

- README는 한국어로 유지한다.
- 레거시 실행 절차와 환경변수 전체 목록은 루트 문서에 복제하지 않는다.
- 공개 API·인터페이스 변경은 없다.
