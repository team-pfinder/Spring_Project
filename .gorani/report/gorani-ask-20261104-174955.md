## 요약

Gorani Ask에 비-Gorani 스킬 fallback 안내 추가

## 종류

개선 (`enhancement`)

## 영역

문서

## 제안

Gorani 스킬에 해당하지 않는 요청이면 먼저 “맞는 Gorani 스킬 없음”을 밝힌 뒤, 현재 세션에 설치된 비-Gorani 스킬 중 직접 맞는 항목이 있을 때 선택적 fallback으로 안내한다. Gorani 스킬과 외부 스킬을 명확히 구분하고, 후보가 없으면 기존처럼 추천을 멈춘다.

## 기대 효과

사용자가 작업을 이어갈 적절한 도구를 찾고, 비-Gorani 스킬을 Gorani 공식 목록으로 오인하지 않는다.

## 현재 동작·양식

Gorani Ask는 매핑에 없는 작업에서 “맞는 gorani 스킬 없음”으로 끝난다. 설치된 외부 스킬 중 적합한 대안이 있는지 확인하는 규칙은 없다.

## 실행 명령

```bash
/gorani-ask — commit/push 요청의 스킬 라우팅
```
