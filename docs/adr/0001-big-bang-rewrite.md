# 레거시를 동결하고 백지 재작성한다

레거시 Lookation은 빌드 도구와 테스트가 없고, 라우팅 체계가 두 개이며, 비즈니스 로직 상당수가 Oracle 프로시저·뷰에 있다. ERD를 새로 설계하면 구 앱과 DB를 공유할 수 없으므로 스트랭글러 방식은 이중 스키마 유지 비용만 만든다. 따라서 `Lookation/`을 읽기 전용으로 동결하고 `server/`에 Spring Boot 애플리케이션을 새로 만든다.

- 대안: 구 WAR와 신규 앱 동시 운영(스트랭글러), 구 DB 공유. 둘 다 ERD 변경과 양립하지 않아 기각.
- 결과: 무중단 이관 안전망이 없다. 대신 도달 가능한 157개 엔드포인트의 패리티 체크리스트로 진척을 관리한다.
- 범위: 죽은 코드(`Sample`, `FileTest`, `insertinfotest`, `TempLocation`, 0바이트 `.action`, 도달 불가 레거시 컨트롤러)는 이관하지 않는다. 정적 약관·정책 페이지는 정적 리소스로 축소한다.
