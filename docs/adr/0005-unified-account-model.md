# 이용자·호스트·관리자를 단일 계정으로 통합한다

레거시는 MEMBER·HOST·ADMIN이 완전히 분리된 테이블이고, 프로필·계좌·블랙리스트·탈퇴·메시지가 9쌍의 거울 테이블로 중복된다. 이를 `accounts` 1개 + 역할(`MEMBER`, `HOST`, `ADMIN`)로 통합한다.

- 한 계정이 `MEMBER`와 `HOST`를 동시에 보유할 수 있다. 호스트 역할은 신청 후 검수를 거쳐 부여한다.
- 호스트의 사업자 정보·정산 계좌는 `host_profiles` 1:1로 분리한다.
- 로그인 식별자는 email(대소문자 무시 unique), 비밀번호는 Argon2id.
- 제재는 `sanctions`(기간제 누적: 1차 7일, 2차 30일, 3차 영구, `ends_at IS NULL` = 영구)로 통일한다. 블랙리스트 회원은 로그인·예약 조회·환전·탈퇴만 허용한다.
- 대안: 레거시처럼 분리 유지, 단일 계정 + 단일 역할. 전자는 중복 테이블이 그대로 남고, 후자는 회원이 호스트가 될 수 없어 기각.
