# 서버 의존성 현재 라인 최신 안정판 업데이트

## 목표

활성 개발 대상 `server/`의 직접 의존성을 현재 언어·프레임워크 라인 안에서 최신 안정판으로 정렬한다. 동결된 `Lookation/`은 제외한다.

## 범위와 결정

- 모드 1 적용: 선택이 없어서 기본값 사용.
- AWS SDK BOM을 `2.46.7`에서 같은 major 최신 안정판 `2.57.8`로 올린다.
- Spring Boot 관리 BOM 버전은 재정의하지 않는다.
- Spring Boot `4.1.2`, Kotlin `2.3.21`, dependency-management 플러그인 `1.1.7`, jOOQ `3.21.9`, Bouncy Castle `1.86`, springdoc `3.2.0`, Testcontainers `2.0.5`, Gradle `9.8.2`는 현재 라인의 최신 안정판이라 유지한다.
- CVE 업데이트 모드는 선택하지 않았지만, `AGENTS.md`의 의존성 변경 규칙에 따라 새 boot JAR을 다시 스캔한다. 기존 보안 보고서는 보존하고 새 날짜 보고서를 만든다.

## 검증

- AWS BOM 및 Secrets Manager가 `2.57.8`로 해석되는지 Gradle `dependencyInsight`로 확인한다.
- Testcontainers BOM이 `2.0.5`로 유지되는지 확인한다.
- `env -u SPRING_PROFILES_ACTIVE ./gradlew build` 통과 확인.
- boot JAR의 Maven 구성요소를 Syft·OSV·Trivy·Grype로 스캔한다.

## 결과

- `server/build.gradle.kts`의 AWS SDK BOM만 `2.57.8`로 갱신.
- 전체 Gradle 테스트 통과, 취약점 스캔 결과 0건.
- 공개 API 변경 없음.
