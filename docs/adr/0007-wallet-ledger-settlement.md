# 마일리지는 원장으로, 정산은 자동으로 한다

레거시는 잔액을 PL/SQL 함수로 재계산하고 충전·환전 이력을 회원/호스트별 테이블 두 벌로 나눠 보관한다. 이를 append-only `wallet_entries`(account, type, amount, ref_type, ref_id) + `wallets.balance` 캐시 컬럼(CHECK >= 0)으로 통일한다.

- 항목 유형: `CHARGE`, `HOLD`(에스크로), `RELEASE`, `REFUND`, `SETTLE`, `FEE`, `WITHDRAWAL`.
- 정산은 자동이다. 이용완료 후 T+1 배치가 수수료를 차감하고 호스트 지갑에 입금한다. 호스트가 신청하는 것은 출금(withdrawal)뿐이다.
- 수수료율은 설정값(기본 10%)이며 원장 항목으로 남긴다.
- 대안: 잔액 컬럼만 유지, 정산도 호스트 신청. 전자는 이력·정합성 검증이 불가능하고, 후는 기획서 PDF(자동 정산)와 충돌해 기각.
- 결과: 정산 후 취소·환불은 음수 원장 항목으로 회수한다.
- 제약: 에스크로 전용 계정을 두지 않는다(2026-11-04 결정). 회원 잔액만 차감되고 자금이 머무는 계정이 없으므로 계정별 원장 합계는 0이 아니며, 취소 페널티·수수료의 수취처가 원장에 나타나지 않는다. 대사·회계 정합성이 필요해지면 시스템 에스크로 계정을 추가한다.
